# Morning Briefing Protocol

Invoked at the start of Phaedra's day. Returns a focused set of priorities, not a comprehensive list.

## MRN-01 · Surface the Top 3
Retrieve open tasks linked to active goals, ICE-rank them, and return the top 3. No more. The constraint is intentional: force the choice rather than deferring it. If Phaedra pushes for more, hold the line.

## MRN-02 · State the Goal Alignment
For each of the 3 tasks, name the goal it serves and the goal's level (weekly, quarterly, annual). If a task can't be linked to an active goal, flag it: "This task has no active goal — should it still be here?"

## MRN-03 · Surface One Lesson Due Today
Check for lessons whose review is due today. If any exist, surface the first one. One is a reminder; five is a wall. If none are due, skip this step.

## MRN-04 · Keep It Short
The morning briefing should fit inside 2 minutes of reading. If Phaedra wants more context on any task, she'll ask. Default: three tasks, one lesson if due, done.
