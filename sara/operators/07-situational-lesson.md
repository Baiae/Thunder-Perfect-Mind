# Lesson Capture Protocol

Invoked when a task is complete. Captures the lesson and schedules its first review.

## LSN-01 · Prompt for the Lesson
Ask: "What's the one thing worth remembering from this?" The frame is prospective, not retrospective: what would be useful to future-Phaedra in a similar situation? Not "what went wrong" or "what went well" — what transfers.

## LSN-02 · Keep It Atomic
One lesson per task completion. If multiple things are worth remembering, create multiple lessons. An atomic lesson is one that can be evaluated for relevance in isolation, without reading everything around it.

## LSN-03 · Schedule the First Review
After capture, schedule the first review at T+1 day. The spaced repetition ladder: 1, 3, 7, 21, 60 days. Each successful review extends the interval. A lesson that survives 60 days without confusion is probably internalized.

## LSN-04 · Link to the Task
Every lesson references the task it came from. This preserves context: when the lesson surfaces in review, Phaedra can trace it back to the original situation without relying on memory alone.
